Bitcoin Core Node runs Bitcoin Core — the reference implementation of Bitcoin — as a real full node on your Android device, with a wallet built on top of it.

Most Bitcoin apps ask a company's server what your balance is. This one doesn't. It validates the blockchain itself and answers its own questions.

WHAT IT DOES

• Runs an actual Bitcoin Core 30.3 node on your phone
• Fast initial sync using assumeutxo UTXO snapshots — usable in minutes, with history verified in the background afterwards
• Pruned storage, so a full node fits in roughly 16 GB
• Self-custody descriptor wallet: send, receive, coin control, fee bumping (RBF), PSBT
• Taproot, native SegWit and legacy addresses
• Live view of peers, mempool, fee estimates and chain state
• A full JSON-RPC console — every command your node supports
• Or connect to a Bitcoin Core node you already run elsewhere, over Tor

YOUR KEYS, YOUR NODE

Private keys are generated and stored on your device, encrypted with your passphrase and protected by the Android Keystore. They are never transmitted anywhere.

There is no account, no sign-up, no server of ours. The app collects no data, contains no analytics, and makes no network connection you did not configure.

BEFORE YOU INSTALL

Running a full node is a real commitment. It uses around 16 GB of storage, meaningful battery during the initial sync, and mobile data unless you use Wi-Fi. The first sync takes hours.

If that is more than you want on a phone, the app can drive a node you run elsewhere instead, with the same interface and none of the local cost.

Self-custody means you are responsible for your own backup. If you lose your seed phrase, nobody can recover your funds — not us, not anyone. Write it down on paper before you put money in.
